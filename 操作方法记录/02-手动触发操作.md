# 手动触发操作

## 目标理解
手动触发是主入口。推荐优先通过 API 调用，而不是直接进容器执行脚本。

## 可用接口
- `POST /custom/sites`
- `GET /custom/sites`
- `POST /custom/schedules`
- `GET /custom/schedules`
- `POST /custom/bioon-news/run`
- `GET /custom/bioon-news/status`
- `GET /custom/bioon-news/latest`
- `POST /custom/sites/{site_code}/run`
- `GET /custom/sites/{site_code}/status`
- `GET /custom/sites/{site_code}/articles`

## 常用命令
### 1. 查看状态
```bash
curl http://localhost:11235/custom/bioon-news/status
```

### 1.1 创建站点配置
```bash
curl -X POST http://localhost:11235/custom/sites \
  -H 'Content-Type: application/json' \
  -d '{
    "site_code": "bioon",
    "site_name": "生物谷资讯",
    "base_url": "https://www.bioon.com/",
    "entry_url": "https://www.bioon.com/",
    "rule_json": {},
    "default_config_json": {},
    "is_enabled": true
  }'
```

### 1.2 创建调度配置
```bash
curl -X POST http://localhost:11235/custom/schedules \
  -H 'Content-Type: application/json' \
  -d '{
    "site_id": 1,
    "cron_expr": "0 * * * *",
    "timezone": "Asia/Shanghai",
    "is_enabled": true
  }'
```

### 2. 手动抓取最新资讯
```bash
curl -X POST http://localhost:11235/custom/sites/bioon/run \
  -H 'Content-Type: application/json' \
  -d '{
    "limit": 100,
    "target_date": "2026-03-30",
    "force_refresh": false,
    "save_raw": false,
    "archive": true
  }'
```

### 3. 查看最近一次结果
```bash
curl http://localhost:11235/custom/sites/bioon/articles
```

## 参数说明
- `limit`：本次最多处理多少篇文章，默认 `100`，用于覆盖当天首页可见的全部资讯
- `target_date`：目标发布日期，格式 `YYYY-MM-DD`；不传时默认取当前本地日期
- `force_refresh`：是否忽略去重状态强制重抓
- `save_raw`：是否保存原始 HTML 到 `raw/`
- `archive`：是否归档本次抓取快照

## 推荐用法
- 要抓“今天全天”：不传 `target_date`，直接使用默认值
- 要补抓历史某天：显式传 `target_date`
- 如果你怀疑当天结果不完整：把 `force_refresh` 设为 `true`

## 规则调整方式
如果你发现字段提取异常，先检查并修改 `deploy/docker/bioon_news_rules.json`，再重启容器服务。常见调整点有：
- `homepage`：首页列表项、标题、摘要、图片、日期选择器
- `detail`：详情页标题、来源时间、摘要、正文选择器
- `defaults`：默认主分类、默认栏目回退值、请求超时

## 返回结果重点字段
- `processed_count`：本次进入处理链路的文章数
- `new_count`：成功抓取并写入结果的新增文章数
- `failed_count`：详情抓取失败数
- `output_file`：最近结果文件路径

## 风险点
- 首页没有新增文章时，`new_count` 可能为 `0`
- 若目标站点短时异常，接口会返回失败信息，需结合状态文件排查
- 若站点配置或调度配置尚未写入 MySQL，数据库驱动接口不会正常工作

## 验证方式
手动执行后，确认：
1. `output_file` 存在
2. `GET /custom/bioon-news/latest` 可返回数据
3. `run_state.json` 中 `last_run_at` 已更新
4. `latest/news_latest.json` 中包含当天截至当前的全集，而不是只包含本次新增项
